# Performance Optimizer Mod

Boost your Minecraft performance with this Fabric mod

## Features

- Shader effect scaling based on distance with toggle option
- View distance management with configurable load radius and buffer zone
- FPS optimizations including graphics mode, particles, entity distance scaling, simulation distance, and view distance settings
- Integration with popular performance mods like Sodium, Lithium, FerriteCore, and Starlight

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/performance-optimizer-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

- Press `F` to toggle Farm Mode
- Press `P` to toggle Performance Mods

## Configuration

The mod can be configured by editing the `config/performanceoptimizermod.json` file. The default configuration is as follows:

```json
{
  "loadRadius": 8,
  "bufferZone": 2
}
```
